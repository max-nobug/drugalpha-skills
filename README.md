## DrugAlpha Biopharma Research Team

Research clinical evidence, competitive landscapes, peak sales, catalysts, financials and valuation, and compare investment cases for one or more companies. The Skill uses DrugAlpha data, your authorized research materials, and public primary sources. Full research defaults to Markdown and Word, with Excel where applicable.

- [Skill directory and AI entry point](skills/drugalpha-research-team)
- [English installation guide](skills/drugalpha-research-team/README.en.md)
- [Chinese installation guide](skills/drugalpha-research-team/README.md)
- [Download the release ZIP](https://github.com/max-nobug/drugalpha-skills/releases/download/v0.2.56/drugalpha-research-team-v0.2.56-public.zip)

To install with an AI assistant, send it the Skill directory URL and ask it to install the entire directory using your client's supported method. For WorkBuddy or clients that import a ZIP, download the release asset and follow your client's import instructions.

[Copy the installation prompt for AI](skills/drugalpha-research-team/README.en.md#copy-this-prompt-to-install-with-ai)

DrugAlpha data access uses your own account. If setup is needed, follow the [official DrugAlpha MCP connection guide](https://github.com/max-nobug/drugalpha-mcp). The public package includes the research workflows, generators, and blank Excel templates. Completed case workbooks and reports are distributed separately.

## DrugAlpha Biopharma Obsidian Vault

Build and maintain a local research vault, archive filings and models, and run read-only queries with links to original files. DrugAlpha MCP is optional for basic vault work and can help match drug names and look up published pipeline records.

- [Skill directory](skills/drugalpha-obsidian-vault)
- [English installation guide](skills/drugalpha-obsidian-vault/README.en.md)
- [Chinese installation guide](skills/drugalpha-obsidian-vault/README.md)
- [Download the Skill ZIP](https://github.com/max-nobug/drugalpha-skills/releases/download/obsidian-v0.1.2/drugalpha-obsidian-vault-v0.1.2.zip)

Send the installation prompt below to your AI assistant. You can also download the Release ZIP and import it if your client supports ZIP imports, or extract it and install the whole directory in your client’s Skill location.

[Copy the installation prompt for AI](skills/drugalpha-obsidian-vault/README.en.md#copy-this-prompt-to-install-with-ai)

The package includes both installation guides, workflow references and vault templates. Local archiving and read-only queries use your authorized local files. For drug matching or published pipeline queries, connect DrugAlpha MCP with your own account. [Official DrugAlpha MCP setup](https://github.com/max-nobug/drugalpha-mcp)
