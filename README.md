## DrugAlpha Biopharma Research Team

Research clinical evidence, competitive landscapes, peak sales, catalysts, financials and valuation, and compare investment cases for one or more companies. The Skill uses DrugAlpha data, your authorized research materials, and public primary sources. Full research defaults to Markdown and Word, with Excel where applicable.

- [Skill directory and AI entry point](skills/drugalpha-research-team)
- [English installation guide](skills/drugalpha-research-team/README.en.md)
- [Chinese installation guide](skills/drugalpha-research-team/README.md)
- [Download the release ZIP](https://github.com/max-nobug/drugalpha-skills/releases/download/v0.2.55/drugalpha-research-team-v0.2.55-public.zip)

To install with an AI assistant, send it the Skill directory URL and ask it to install the entire directory using your client's supported method. For WorkBuddy or clients that import a ZIP, download the release asset and follow your client's import instructions.

> Install the DrugAlpha Biopharma Research Team Skill from https://github.com/max-nobug/drugalpha-skills/tree/main/skills/drugalpha-research-team. Follow the instructions for my client and verify my existing DrugAlpha MCP connection.

DrugAlpha data access uses your own account. If setup is needed, follow the [official DrugAlpha MCP connection guide](https://github.com/max-nobug/drugalpha-mcp). The public package includes the research workflows, generators, and blank Excel templates. Completed case workbooks and reports are distributed separately.
