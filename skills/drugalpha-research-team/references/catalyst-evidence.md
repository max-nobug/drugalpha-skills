# 催化剂研究员：联网补证与投资判断

## 1. 从事件问题寻找一手证据

DrugAlpha用于候选发现和已有披露，公开联网补原文、最新修订和遗漏事件。先有明确问题再检索，连续两轮无有效新增停止。保留所读全文/页码范围；搜索摘要、无法打开正文和原始全文已读不能混用。不同网站转载同一新闻稿只算一个来源。

| 问题 | 明确路径与示例检索词 | 核到什么才可下结论 |
|---|---|---|
| 读出时间与新数据 | 公司官网IR→新闻稿/业绩演示/定期报告；ClinicalTrials.gov→具体NCT及History；中国药物临床试验登记与信息公示平台→具体CTR；PubMed→DOI→期刊；`"药物别名" "trial名" topline results` | 公司最新指引、实际公开结果、确切队列和截止时间；注册预计完成日不能替代首次公开结果日期 |
| 美国监管 | FDA官网新闻/Drugs@FDA→标签/审评资料；公司IR→受理及审评目标日/补充材料；`site:fda.gov "drug"` | 申报、受理、优先审评、目标日、批准或CRL分别核；目标日不预先写成获批日 |
| 中国监管 | NMPA→批准信息；CDE→受理/登记/公示；公司公告交叉核药名/受理号/适应症；`site:cde.org.cn "药物代号"` | 具体产品、剂量/人群和办理节点；无官方或公司明确日期不按一般周期推定确定获批日 |
| 欧洲及其他地区 | EMA→具体药物/CHMP意见/EPAR；欧盟委员会决定或对应国家监管原文；公司IR补细节 | CHMP意见与最终授权决定分开，不能把美国进度外推其他地区 |
| 会议 | 当届ASCO/ESMO/AACR/ASH等官网→项目/摘要库→试验号/药名→原摘要/报告；公司海报页交叉核 | 入选身份、具体摘要、公开与报告时间、原时区、是否新截止/随访；不能只看大会总日期 |
| BD/权益 | 双方IR→交易公告→SEC合同附件/10-Q/10-K或港交所/交易所公告；`"drug" license agreement upfront royalty` | 资产及地区、选择权行使、签约与生效、首款/条件付款/里程碑/版税、成本和退出条件；缺条款说明未披露 |
| 真实市场预期/股价 | 有日期的研报、业绩会问答和可核指标预期；用户指定预期来源；行情按当前可用金融工具与市场覆盖获取 | 预期需对象、指标、时间和样本范围；单篇观点不能称全市场共识，股价事实不能替代预期证据 |

常用入口：[ClinicalTrials.gov](https://clinicaltrials.gov/)、[中国临床试验登记](http://www.chinadrugtrials.org.cn/)、[PubMed](https://pubmed.ncbi.nlm.nih.gov/)、[FDA Drugs@FDA](https://www.accessdata.fda.gov/scripts/cder/daf/)、[NMPA](https://www.nmpa.gov.cn/)、[CDE](https://www.cde.org.cn/)、[EMA](https://www.ema.europa.eu/)、[SEC EDGAR](https://www.sec.gov/edgar/search/)、[港交所披露易](https://www.hkexnews.hk/)。检索结果链接必须实际核对后引用，不能把入口当具体事件的证据。

## 2. 时间和信息增量的细节

四个时间分别记录：资料公布日、数据截止/研究完成日、计划事件窗口、实际公开/发生日。日期精度不人为提升；精确到时点的会议/公告保留原时区，需判断交易时段时按当日夏令时规则换算北京时间和上市地交易日，不能全年用固定时差。来源只给日期时不猜盘前盘后。

会议需拆标题/入选公告、常规摘要、LBA解禁、海报/口头报告、后续全文。会议展示可能只是已公开数据再呈现，也可能有更新患者/随访/亚组；逐项判断新增内容。不要预先套上一届摘要发布时间或认为所有LBA在同日解禁。[ASCO政策](https://www.asco.org/annual-meeting/abstracts-presentations/abstract-policies-embargoes-exceptions)与[当届发布说明](https://www.asco.org/ampresskit)仅作核查入口，每次读当前会议自己的规则。

ClinicalTrials.gov的Primary Completion Date、Study Completion Date、估计/实际状态以及入组完成分开；OS事件驱动研究不能凭入组数或既往中位OS精确算公开日。旧摘要与新报告不同截止日期时，判断确认缓解增加、患者分母变化和随访延长，不以一次变动即断言疗效改善/恶化。

对影响判断的试验或监管窗口，按同一试验、队列、市场和事件比对上一版与最新一手记录。记录原值、新值、更新日及影响，同时保留两版出处。登记日期变化和公司读出指引分别核对，解释是否改变本品与竞品先后顺序。样本量、暂停、终止等变化按相同方法处理。仅能核实当前值时，保留当前状态并注明历史版本缺口。

核监管事件时，逐市场查看递交、受理、目标日、咨询委员会、最终决定和正式标签中与本题有关的节点。标签扩展交代新增人群、治疗线及仍存在的限制。

PDUFA是审评目标节点，可能有批准、CRL或延期等结果；不给统一必批日期，核目标日是否被修订。[FDA CRL说明](https://www.fda.gov/drugs/laws-acts-and-rules/complete-response-letter-final-rule)解释未达到批准要求的审评结果，不把CRL一律解释为药物失效；有制造、临床等不同原因，必须看本事件披露。不同地区的沟通/受理/意见/最终决定不能混写。

## 3. 把事件变成买方可用的判断

每个重要事件按以下链条推理：

**已有事实和研究判断 → 本次新增信息 → 改变哪项关键假设 → 对谁的哪部分权益有影响 → 什么证据会推翻这一解释。**

- 数据：随机结果能否确立疗效，还是早期样本仅提供信号？关键亚组是否决定真实可服务人群？主要终点达标但效应小、OS未成熟或毒性增加，未必支持原先商业定位。竞争药好数据可验证机制，也可抬高本资产门槛。
- 监管：批准是否覆盖核心患者、能否按原方案使用、是否依赖额外试验或生产整改？广标签带来范围变化，但不意味着所有亚组已有同等证据，也不意味着即时销售。
- 会议：重点看首次公开的新证据及关键问题是否解决，口头报告、LBA和顶刊发表本身不能替代结果质量。
- BD：真实近期现金能否支持下一里程碑？是否只是购买选择权而非已经完成全部授权？首付款是否含股权投资或附条件款？高潜在总额是否主要是远期销售里程碑？分担成本、归还权益和终止条款可能改变净收益。

BD底稿分列首付款、股权投资、近期待条件款、研发/注册/销售里程碑、版税/利润分成、成本承担；未公开填未披露。签约、生效、触发、实际收款、会计确认逐层核，不把合同最高额作到账或收入；不得将同一款项在现金余额、里程碑和估值中重复计算。交财务处理最终会计与估值。

没有可核市场预期时，明确给出资产基本面判断和后续条件，不用“超预期、被低估、市场未充分定价、必将重估”填补证据。若用户要事件后股价分析，取得真实行情、事件首次公开时间、对应交易日和基准，核市场/行业/财报/融资等同期因素；事件后上涨只能称同期表现，单窗口不能确立因果。用户未问时不为增加篇幅强算收益率。

## 4. 复核用的典型情境（方法示例，不是实际公司事实）

| 输入情境 | 合格判断 |
|---|---|
| 平台写Q4读出，10月公告已经公布主要结果，11月大会再报告 | Q4不再整条列未来首次读出；11月只研究可能更新的随访/亚组，未承诺新数据则不猜 |
| 标杆药总体ORR较高，但目标竞品只针对G12D | 找标杆G12D的ORR、持续性、生存和安全性；总体数据不能代替目标亚组，最终仍区分跨试验观察与可靠优效 |
| 注册库预计6月完成，当前10月仍无结果公告 | 不写6月“应已读出”或自行平移到Q4；核注册更新及公司指引，无结果标未确认，保留缺口 |
| BD最高总额很高，只有小额选择权费、以后由伙伴决定是否行权 | 只确认已披露付款及条件，不把完整许可写成落地；分析未来现金与权利让渡，待行权验证 |
| 催化剂查询零条或第一页全是宽时间区间 | 检查对象、分页、覆盖和未知时间，关键事件联网补；不能称无催化剂或指定某天发生 |
| 同靶点海外公司读出好数据 | 核机制、临床适用人群与权益，分别判断机制验证与竞争压力；不能自动把国内同靶点公司列利好受益名单 |

这些情境用于检查实际行为，不要求最终报告把检查表全部展示。研究底稿保留反证和缺口，用户简版按[手册输出框架](catalyst-workflow.md#4-固定输出框架简洁判断在先)呈现。

## 5. 先固定判断，再评估事件改变了什么

对最重要事件，内部先留一条“事件前已知证据／当前资产定位→尚未解决的关键问题→什么新增结果足以改变判断”。本次研究发生在事件后时，只能用可追溯的此前材料还原，不能把事后结论冒充事前判断。原有研究记录存在时保留原版本，明确变化而非覆盖历史。

**三种参照分别核。** 预设统计成功标准、商业上有意义的临床门槛、真实市场预期不是一回事。统计方案及临床门槛交临床核，市场预期注明来源日期、指标和覆盖范围；仅有公司指引不能称共识。研究成功但对现标准没有足够增量，可能只支持推进而不足以上调竞争定位；未有预期证据时仍可给这种明确基本面结论，不编“超预期”。

**事件会不会发生，与结果会不会好分开。** 已确定报告日期不能推出正面结果概率高；会议入选也不意味着会有新数据。时间精度和时间依据分别记录：确切日/季度窗口/未知，与公司指引/监管目标/官方日程/研究推算独立，不由来源权威把宽窗口压成一天。

**优先看依赖和后果。** 对决定性事件核其前置条件及最重要的后续依赖：数据能否支持申报、批准标签是否仍覆盖原市场、BD是否仍需行权/生效、现金能否撑到公开结果。相关事件共享同一风险，不能把数据、会议、论文、申报分别叠加估值，也不把多项正面事件机械相加成高胜率。临床、商业化和财务分别接变化；现金可能在读出前不足时，该约束应进入首段，而非只列一个更近的常规会议。

**用结果变化表替代热度打分。** 简版仍用原表，对核心事件写清“原来知道什么／还要新增什么—强化/维持/削弱的具体条件—改哪项判断及交接给谁”。排序依据是能解决什么不确定性，不能仅按近期或事件数量。事后以同一条件对照实际结果，注明未解决问题和受影响假设；复核若发现目标日冒充获批、重复信息充当新增或结果不影响定位，退回对应判断。研究动作是补证/修订模型条件，不自动生成交易指令或订阅监控。
