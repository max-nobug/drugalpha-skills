# 临床数据比较与PubMed补证流程

本流程是临床研究员的核心分析工作，与[执行手册](clinical-workflow.md)和[MCP指引](clinical-mcp.md)配合使用。默认研究目标包含目标药物与相关治疗的临床优劣；只解释术语或只读指定研究时按用户范围裁剪。

## 1. 先明确比较问题与对象

按疾病、阶段、线数、标志物、既往药物与耐药状态、CNS状态、治疗方案和地区建立比较问题。用户给出的条件保留；不同人群分开比较。药物单药与联合方案不混为同一干预。

比较对象优先覆盖：同场景标准治疗、实际直接替代方案、同场景且可能改变定位的重要研发竞品。可以包含不同靶点/技术路线，只要它们是该患者的真实治疗选择；相同靶点但不同患者/线数可排除并给理由。临床研究员负责最终入选理由，商业化提供当前状态与竞品线索。

建立覆盖清单：药物/方案、为何纳入、目标患者、关键研究、DrugAlpha已得数据、缺失项、公开补证状态。每个核心比较对象至少核其关键疗效证据与适用的安全性资料，核是否存在更成熟的更新；不预设必须凑足若干药物。

同时按[独立执行手册步骤四、五](clinical-workflow.md#3-执行流程)建立关键亚组取证记录。宽人群标杆与窄人群候选比较时，标杆在候选目标人群中的数据是必查项；不能只列总体结果就将其定位为该亚组标杆。亚组ORR、PFS和OS分别找，不以取得其中一个终点视为全部核清。

### 逐药核查最新随机对照研究

对每个入选药物单独核查。先取 DrugAlpha 临床记录，再用通用名或研发代号＋病种＋治疗线数＋randomized / phase 3 检索试验注册库和 PubMed。即使已找到长期单臂随访，也要查截至研究日的相关学会会议摘要与口头报告。已有随机研究时按注册号或试验名追踪最新读出，分别核对各终点的分析人群、截点和来源。

交付前逐药记录「已公布随机结果 / 已注册但未公布结果 / 在所查来源未检出 / 无法核实」。阳性、阴性和提前终止的随机研究均须纳入。已有结果就列出对照方案、核心终点及效应量，必要时用单臂随访补充成熟度。未找到时交代检索范围，避免将检索缺口写成没有随机研究。结论中的每个药均需与该记录一致。

比较肿瘤药长期获益时，分别回答 PFS 是否支持延缓进展、OS 是否证实延长生命。标清尚未成熟、交叉治疗或单臂观察等限制。跨试验只判断证据强弱。

### 必做：标准治疗核心终点比较

凡评价疗效、临床价值或资产竞争力，即使用户只问一个药、一次会议数据，也主动执行以下步骤，不等用户点名要求对比。纯术语解释、试验设计说明或用户明确限定只读指定材料时按范围裁剪，并说明未作外部竞争判断。

1. **选当前真实治疗基准。** 按地区、线数、组织学、标志物及既往治疗，从DrugAlpha指南与临床证据确定当前标准方案，并核指南/标签和关键研究。试验自身对照与当前标准治疗分别核：胜过旧对照不自动具有当前竞争优势。不同机制只要是真实替代治疗也应纳入；不能只挑较弱方案或较旧截点。
2. **先定决定临床价值的终点。** 根据疾病、治疗目标和试验设计，固定本次最重要的疗效终点及必要的持续性、生存和安全性指标，再看本药亮点。不能因为ORR最高就改用ORR主导所有判断；也不要求所有疾病机械以OS或PFS排名。
3. **取得同场景数字。** 在底稿记录“患者/方案与研究、截点和来源、分析集/样本、核心终点结果及CI/成熟度、可比性、对定位的影响”。目标药与标准治疗均须取证；数据库缺失，按第3—4节主动查PubMed、原文附录、会议和监管资料。优先相同组织学、标志物阈值、线数及联合方案；关键亚组按终点分别查。不因拿到一个总体中位数就视为完成。
4. **让比较改变判断。** 明确回答核心终点相对标准治疗是否显示差异化，以及这如何支持、收窄或否定当前竞争定位。已成熟核心终点接近或没有数值优势时，直接写“目前未显示该终点的差异化优势”，降低仅凭早期活性形成的乐观定位；如仍看好，必须另给足以支持该定位的具体证据及适用患者。高ORR、新剂量小队列NR、机制新颖不能抵消成熟队列平淡/不利的核心终点；不同剂量、队列和成熟度分开判断。可靠随机证据支持优势时也应明确承认，不预设负面结论。
5. **限制结论强度。** 未调整跨试验只能判断观察差异及竞争信号，不能将“未显示优势”写成已证实更差或等效。只有全人群、历史年代或不匹配方案的数据时，标为背景参照，继续寻找匹配证据；两轮定向补证仍无新增则交代缺口，不能把背景数值当该亚组的有效胜负基准。尚未成熟或缺失意味着优势待验证，不意味着无效，也不允许宣称核心终点领先。

**成稿与验收：** 核心表或紧邻正文必须保留目标药与标准治疗的决定性数字、来源和最重要的可比性限制；总体结论必须回应比较结果。只有治疗背景、没有数字或没有定位影响，不满足交付要求。确实取不到时写具体缺口和结论收窄，不无限检索、不凭记忆填数。完整取证过程留底稿，不另加一套冗长报告。

## 2. DrugAlpha取证后检查比较缺口

按 MCP 指引查临床资料、指南及必要管线。已知药物且连接支持时，按药名查临床并用原始适应症条件筛选。得到候选来源后，按药物、试验、治疗臂、数据截点和亚组拆分，不把来源条数当研究数。

逐项检查：是否缺主要比较药物；是否只有早期/旧截点；是否缺同线数、关键亚组或当前剂量；是否缺PFS/OS/DoR、CNS或重要安全性；是否缺设计、分母、评估方式、CI或随访而影响判断。任一关键缺口触发主动联网补证。已得到目标药物ORR，不代表比较工作完成。

## 3. 主动PubMed检索

无需用户再次提供链接。使用当前可用联网搜索或浏览工具访问PubMed；若存在实际可用的文献连接器，可按其说明调用。不假定已安装PubMed MCP，也不编造工具名。

1. **整理检索词**：从已核来源获取通用名、研发代号、旧代号、商品名、试验简称/登记号与疾病英文名；确认别名属于同一药，不把仅名称相近的药合并。
2. **逐药找关键研究**：先查药名/代号/登记号及疾病，再按线数和治疗场景筛文献。检索目标药物与比较药物，不能只检索目标公司的产品。
3. **核较新与长期结果**：沿同试验查询更新随访、最终OS、CNS、安全性、患者报告结局及补充材料；先确认适用性，再选用于该问题的截点。较新摘要与较旧全文各有阅读范围和完整性，不能机械互相替代。
4. **查漏**：查关键论文参考文献、相关论文及后续引用；综述/Meta分析用于发现原研究与异质性线索，核心数字尽量回到原研究。
5. **取原文**：记录PMID、DOI、试验号和标题，从期刊页、PMC或其他合法可访问原文入口读取正文、表格、脚注、附录与方案；只有摘要时明确标注摘要可确认的内容。

仅采用截至本次研究日已经公开的材料，区分电子发表日、纸本卷期、登记更新日和临床数据截点；不能把未来卷期或登记预计日期当已发生结果。

可用PubMed检索模板（替换尖括号中的真实词，不直接照抄）：

```text
(<通用名>[tiab] OR <研发代号>[tiab] OR <已核旧代号>[tiab])
AND (<疾病英文名>[tiab] OR <已核疾病别名>[tiab])

<试验登记号> OR <已核试验简称>

(<药名>[tiab] OR <试验简称>[tiab])
AND (follow-up[tiab] OR survival[tiab] OR safety[tiab] OR intracranial[tiab])
```

根据问题选词，不把全部模板AND在一起。用OR包含药物别名，AND组合概念；可添加已确认的MeSH词，并检查PubMed实际检索翻译。初查不过早依赖文章类型、语言、日期或免费全文过滤，防止漏掉新近或未充分索引的关键研究。筛选条件和最终文献纳入理由留记录。

文献检索可以先用较宽关键词提高召回，但纳入比较时必须逐篇核原始患者条件；这不改变DrugAlpha适应症查询必须保留用户原文条件的要求。无法核实条件的研究放在背景区，不能作为目标患者的有效比较证据。

## 4. PubMed以外的补充路径

| 缺口 | 优先查找位置与核验内容 |
|---|---|
| 最新会议、尚未发表研究 | ASCO、ESMO、IASLC/WCLC、ASH等对应学会官方摘要/演示；核摘要号、版本、截点、分析集与后续正式论文 |
| 设计/主要终点/入排 | ClinicalTrials.gov、中国药物临床试验登记与信息公示平台等正式登记及可得方案；核更新历史，登记预计完成不等于公开读出 |
| 注册性研究与标签 | FDA、EMA、NMPA/CDE等公开审评、批准与正式说明书，核适应症、人群、剂量和审评数据集 |
| 公司披露有独有数据 | 交易所公告、定期报告、公司官方会议材料；注明属于公司披露，不冒称独立发表论文 |
| 治疗基准改变 | 指南发布组织和对应关键研究；核地区、版本及获批范围 |

官方摘要与论文缺失时可以用公司正式披露，明确阅读层次及局限。付费墙或无法访问时，不把媒体/搜索片段拼成全文。两轮针对同一缺口无新增后停止，说明查了哪些范围和还缺什么；不停止其他仍可推进的比较项。

不能因数据库连续无匹配而跳过用户已要求的公开补证。至少实际执行相关且可用的PubMed或其他一手公开渠道检索；公开渠道本身无法访问时说明限制，不能声称已经补齐。

## 5. 可比性核验：先判断哪些数据能放在一起

比较矩阵前列明下列差异及其可能影响，不只写“跨试验不可比”：

- 疾病、线数、既往具体治疗/耐药、标志物亚型、CNS状态和体能状态等效应修饰因素。
- 随机/单臂、对照方案、剂量与联合用药、入组年代/地区、后续治疗及交叉用药。
- ITT/FAS/PPS等分析集、样本与事件数、独立评审/研究者、确认/最佳ORR及标准。
- 数据截点、随访长度、暴露和数据成熟度；相同时间点是否可取得。

分三类组织证据：同一随机研究直接比较；有适当方法及假设支撑的调整后间接比较；未经调整的跨试验描述。不同类的结论强度分别表述。人群根本不同且无法分层时拆表，不做总排名。

复杂比较按[方法选择与展示指引](clinical-methods-presentation.md#2-先选择能支持哪一级比较)先固定目标人群、对照和效应修饰因素；对照同名不代表组成一致。各药相对自身对照的随机证据和药间间接结论分别说明支持程度；预后因素、效应修饰及未测因素不可互相替代。没有所需IPD、重叠或完整假设，不启动看似校正的MAIC/STC或临时图像重建。

对决定结论的终点逐个标明比较基础：同试验随机对照、符合前提的锚定间接比较、匹配人群的描述性并列，或只作背景。一个试验对可以在PFS上有可用参照、在OS上仍缺关键资料。每个关键数字保留药物/试验、治疗臂、分析集和分母、截点、评估者及原文页码或图表号。关键图表或口头读数回到原页确认单位、95% CI与脚注；同一试验的多个截点按终点选用并标明。

**自身对照差异必须解释。** 两项随机试验对照组的关键终点明显分离，或绝对结果和相对自身对照的效果给出不同排序时，并列「各药的绝对结果」「各自对照的绝对结果」「各药相对自身对照的效应」。依次核对对照具体方案和用药构成、入组线数与既往暴露、关键基线和地区、PFS评估频率/删失、OS后续治疗/交叉及成熟度。把原资料已证实的差异和仍待验证的解释分开，并说明哪一项足以改变排序、下一步要补哪条证据。只有名称相同的医生选择治疗也逐项核组成。若对照差异无法解释且可能改变判断，保留各自试验内的效果，将药间比较降为描述性。

**核查退出与暴露。** 单臂或早期试验出现高ORR时，核入组人数、疗效可评估分母、排除人数及原因，追查首次影像评估前的进展、死亡或停药。存在PFS删失、OS交叉或安全性观察期不齐时，写明影响哪个终点及可能的方向，无法确定方向时如实说明。比较耐受性时对齐暴露和归因，按资料核因毒性中断、减量、永久停药及关键严重风险；仅保留会影响选药或可持续用药的发现进入简报。

## 6. 逐维度比较临床优劣

| 维度 | 要回答的问题与输出 |
|---|---|
| 缓解能力 | 确认ORR/CR及CI、起效时间和症状改善；高ORR是否伴DoR/PFS支持，是否由人群选择或评估差异解释 |
| 持续控制与生存 | PFS、DoR、OS及同时间点生存率；同时看效应、绝对结果、事件数和成熟度。NR不是优于已达到中位数的证明 |
| CNS或疾病特异价值 | 同脑转移背景下的颅内响应、持续控制、预防进展及相应分母；其他疾病选择其临床重要终点 |
| 安全性与可持续用药 | 重点≥3级毒性、SAE、停药/减量/中断、致死事件和长期暴露；TEAE/TRAE及归因一致，不能仅比较一个总AE比例 |
| 生活质量与便利性 | 有数据的患者报告结局、症状、给药负担；剂型/频率便利与已证实依从性获益分开 |
| 证据可信与适用性 | 设计、对照、样本、随访、缺失/删失、亚组及偏倚；数据是否支持该患者或拟标签 |

每个维度写出：观察差异、支持与反对证据、主要混杂、可支持的判断和待验证条件。直接证据充分时明确指出优势或劣势；只有跨试验数据时可表述“观察到更高/更低”“提示某方面潜力”，同时具体解释为什么尚不能作因果优劣结论。不能以谨慎措辞代替分析，也不能为了得出结论忽略不可比性。

必要描述计算可以给同口径绝对差（百分比结果用百分点）或同时间点差异，并显示输入和来源；跨试验描述差不是因果效应，不据此算NNT。不同研究的中位PFS之比不是HR，也不能用HR简单相除构造新比较。未报告CI不自行补，不能用CI重叠判断优效/非劣。

存在可用的高质量间接比较或网络Meta分析时，核研究纳入、共同对照、患者效应修饰因素、异质性、可传递性与不一致性，并追溯原研究。仅有共同对照不自动满足间接比较条件。MAIC/STC等调整还要核数据可得性、重叠与方法假设；不能为补齐矩阵临时编造调整后效应或患者级数据。需要新建正式统计比较时，将方法与数据前提单列为专项分析。

## 7. 明确结论：先回答谁的数据更好

下结论前执行[重要洞见分析](clinical-methods-insights.md)，从主要不一致中形成并检验解释：除观察差异，还要说明为什么、最强反证及对患者或药物定位的影响。不能用更长的数据清单或常规风险提示代替这一步。

比较成稿开头必须直接回答本次患者场景下哪款药物的数据更有优势，以及总体更看好哪个产品的临床竞争力。先下结论，再解释决定性指标、优势短板、证据性质和可能改变结论的条件。不得以数据清单或“各有特点、值得期待”代替判断。

总体结论根据本疾病的临床需求、主要终点、获益持续性、重要安全性和证据成熟度综合作出，说明哪些因素主导判断。不预设所有疾病一律按OS、PFS或ORR排，也不按指标数量投票、给任意权重总分。疗效强度和证据充分程度分别比较：证据更成熟不自动代表疗效更强，单个指标更高不自动代表总体更好。

| 当前证据能够支持什么 | 应采用的明确表达 |
|---|---|
| 有可靠相对证据支持某维度优劣 | “A在该人群的某终点优于/劣于B”，给效应、统计与临床意义及来源；不外推未验证维度 |
| 有足够相关资料支持综合研究倾向，但未证明相对优效 | “基于当前公开数据，综合临床竞争力更看好A；决定因素为……。这是研究判断，相对B的临床优效尚未被证实” |
| 不同产品优势针对不同患者需求 | “需要重点解决X问题时A数据更有优势；Y场景B更有优势。总体倾向由本次患者场景决定”；场景未定且改变判断时明确请求确认 |
| 指标呈接近的描述性结果 | 指明哪些指标观察值接近、哪些仍有差异；不能写成已证实等效/非劣，仍须判断能否支持总体倾向 |
| 关键证据不够或人群无法对齐，无法建立可靠倾向 | “当前无法分出A与B的临床优劣；缺少的决定性证据是……，已经补查……”。不填造赢家，不把无数据写成更差 |

每个主要比较维度给明确判定：A更有优势、B更有优势、描述性结果接近或目前无法判断，并附证据性质和影响最大的限制。某维度未知不阻止其他有依据的维度作出结论；可能改变总体判断的未知不能藏在表格脚注。

推荐结论结构（仅为写法模板，不代表真实药物结果）：

> **总体判断：基于当前公开临床数据，更看好A在〔具体患者场景〕的临床竞争力。**主要依据是〔决定性的疗效、持续性或安全性证据〕。A的明确短板为〔证据〕；B在〔维度〕更有优势。总体倾向属于〔直接相对证据支持/调整后间接证据/跨试验综合研究判断〕，〔关键限制或新增数据〕可能改变结论。

如果现有资料不足，先执行本流程的主动补证，再采用无法分出优劣的结论。不能仅因没有头对头研究就停止分析；也不能把“更看好A”的研究倾向改写为确定优效或个体用药建议。用户所需的明确结论不构成制造确定性的理由。

## 8. 必交的比较成果

以下成果应在研究底稿中齐备；面向用户默认按[独立执行手册第7节](clinical-workflow.md#7-标准交付与成员交接)压缩为总体结论、核心数据表、关键洞见与药物定位、关键限制。不要把下列四份完整材料连续粘贴给用户；关键不利信号和必要口径须在简版保留。

**A. 可比性表**：药物/方案、研究/截点、人群与既往治疗、设计/对照、分析集/样本、CNS、评估方式、随访/成熟度、重要差异和来源。

**B. 疗效与安全性矩阵**：在同一患者场景下并列ORR/CR、DoR、PFS、OS、同时间点率、CNS结局、重点毒性与停药。只列相关且实际取得的指标，缺失留明，不凑数；初治/经治等另分矩阵。

简版可借鉴[SoF式核心表与原图用法](clinical-methods-presentation.md#4-把证据汇总表改成买方能读的形式)，同时呈现绝对结果、相对效应和比较边界；不假称已完成系统综述/GRADE。用于解释异质性时优先同层级配对表/原森林图，涉及时间变化时看原KM及风险集；不虚构合并HR、NNT或评分。

**C. 优劣判断**：按第7节首先给总体判断及主导理由，再对每个核心药物给“适用人群—比较对象—具体优势—具体短板—证据依据—尚待验证”的结论。可以部分维度有优势、部分有短板；不强行给综合总分或无依据的Best-in-class标签。

**D. 覆盖与补证记录**：哪些来自DrugAlpha，哪些由PubMed/会议/监管等补齐；关键比较对象是否覆盖、缺什么及对结论的影响。查询式/检索日/纳入排除理由可保存在内部底稿；成稿保留来源与重要缺口，不堆工具日志。

没有可比数据时仍交付为何不可比、补查范围和可验证部分，不把“未找到”写成药物更差。仅罗列本公司数据或一句“跨试验不可比”，不满足综合临床研究交付要求。
