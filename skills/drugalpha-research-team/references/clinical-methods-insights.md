# 从临床数据形成重要洞见

用于临床研究员核验主要研究之后、形成结论之前。目标是发现能改变患者分层、相对竞争定位或证据可信度的信息；研究深度不以报告长度衡量。隐藏信息不等于负面信息，也不要求每次发现新结论。

前置工作必须完成[独立执行手册步骤四、五的关键亚组清单和取证记录](clinical-workflow.md#3-执行流程)，不能只凭已看到的总体异常挑两三个有趣点。优先从“比较标杆在竞品目标亚组中表现如何”提问；用总体生存证据强来跳过亚组缩瘤数据，属于遗漏而非洞见取舍。

## 1. 从异常或不一致形成问题

先对实际取得的原始结果表、瀑布图、泳道图、亚组森林图及脚注做细节扫描，再从本次真实数据选择最可能改变判断的两三个问题。不能只读取摘要中的ORR/PFS/OS总值，等发现总体异常才看细节；全文或图像不可得时明确阅读缺口。将候选问题记为“观察—假设—需要的证据”，补查只为检验假设。

### 先扫容易漏掉的观察事实

- **缓解深度和罕见反应**：拆CR/PR/SD/PD与未评估者，主动记录少数CR或深度缓解。逐例核肿瘤类型、分子背景、剂量、既往线数、确认状态、出现时间及持续性（披露才填）；“两例CR”与“高ORR”可能表达不同价值。病灶缩小100%、靶病灶消失、代谢完全缓解和RECIST总体CR不能混同，uCR不能省略为已确认CR。
- **患者级轨迹及分母**：瀑布柱、泳道、蜘蛛图与反应表交叉核对；无后续扫描或未画入患者不自动从分析分母删除。区分累计入组、可评估、达到指定随访、剂量可评估和安全集；个别特别好的患者不能代替总体结果。未取得个体资料时保留未知，不能臆测CR来自哪位患者。
- **最弱亚组与例外**：对同一研究关键组织学、标志物、脑转移、地区和既往治疗亚组同时找最强与最弱信号。尤其核总体获益是否掩盖某个关键人群相对获益较弱、CI宽或终点方向不一致；不只引用支持产品优势的亚组。优先解释会改变拟适用人群和竞品定位的差异。
- **跨终点的不一致**：同一亚组内核ORR/CR、PFS和OS的衔接；有PFS优势但OS支持较弱，应作为需解释的问题。不同截点、分母、评估者或未成熟结果要分别标示，不能写成获益必然消失；若统计充分且方向确实不利，应直接指出，不用套话弱化。

这些扫描先产出“发现了什么”，再讨论“意味着什么”。有可核事实的积极细节同样重要；不能把洞见分析缩成统计局限清单。

**负面发现须做同层级反查。**每个用于定位的亚组效应附研究、截点、总体/ITT或具体线数、标志物/检测、评估者与终点；发现总体某地区/病位信号弱时，追本问题对应线数和可得交集。总体负面、三线负面、单因素表达亚组不是同一命题。缺交集就说明，不把它们拼成“三线高表达某地区无效”；同时报告可能改变原解读的正向切片。具体可信度问题见[ICEMAN借鉴与配对表](clinical-methods-presentation.md#3-亚组差异先判断可信度再用于定位)。

**偏好形成后核一个反转指标。**若偏好由ORR主导，查CR/深度、DoR与早期失败；由低停药主导，查严重事件、死亡、剂量调整与暴露；由较低HR主导，查对照、固定时点及主要/探索性质。不能把较高缓解率叫更深缓解，也不能把更多CR当更长生存。方法来源未解释的差值保留假设，不臆定回归、分层或删失算法。

| 观察方向 | 追问及取证 |
|---|---|
| 总体很好，关键亚组表现不同 | 核预设/事后、分母、事件、CI及交互检验；看效应方向与精度。不以一组显著、另一组不显著认定效应不同，不把亚组点估计当已验证的患者选择规则 |
| 同类研究的对照表现悬殊 | 核地区、体能、脑转移、标志物分布、治疗与后线可及性及评估方式；提出具体可能解释及方向，不把对照弱当成已证事实，不用跨研究HR相除判优 |
| ORR高，但持续控制不相称 | 对齐分析集、缓解确认、缓解者条件分母、DoR、早期进展及随访；区分更易缩小、持续更久、降低早期失败三种价值，不仅看一个中位数 |
| PFS好，OS方向不同或不稳定 | 查死亡事件、计划信息比例、交叉和后线治疗、删失及预设估计目标；随机总体结果和调整后模型分别解释，不因存在交叉就抹去不利OS，不把不成熟解释成未来一定改善 |
| 中位数、HR、固定时点率给出不同印象 | 实际读取原始KM图、风险集、删失标记和随访定义，关注早期风险、曲线交叉、长尾和末端少数事件。未取得图表就不能声称曲线支持；不临时重建患者级数据，不把曲线形状当机制证明 |
| 高缓解来自特殊分析集 | 核ITT/FAS/PPP、可评估集、排除人数与理由、缺失扫描及敏感性分析；说明选择可能如何改变观察值，不在无人数时推算“真实ORR” |
| 毒性比例低或停药少 | 对齐暴露、TEAE/TRAE、严重性与等级、疾病进展造成的早停及不同药物停药定义；同时核死亡、生活质量与剂量强度。无暴露校正数据不虚构校正率，不用单项毒性宣布最安全 |
| 新研究似乎推翻旧标准 | 核真正的对照方案、组织学、地区及标志物范围；明确证据新增覆盖了哪一比较，尚缺哪一比较。优于某免疫单药不自动优于免疫化疗，某联合方案的胜出不能转移到该药单药 |
| 摘要结论强于数据本身 | 回看方案/SAP、α分配、期中边界、主要/次要终点与多重性、版本变更。区分正式检验、描述性结果与作者主张，不仅依据P值或CI是否跨1 |

## 2. 每条洞见必须完成的论证

1. **观察事实**：本次读到的具体数字或图表位置、研究/截点/人群及来源。
2. **临床含义**：该信息如何改变获益对象、获益形式、净获益或相对竞争定位；必须比“随访未成熟”“跨试验不可比”更具体。
3. **替代解释与反证**：至少考虑一个可能使解释不成立的因素；区分已核实与待验证。
4. **判断的改动**：写明原本可能得出什么结论，现在应如何收窄、加强或改变；不是只增加一句风险提示。
5. **验证条件**：哪项新增数据能支持或推翻这个解释，已查不到时如实记录。

完整论证保留在底稿。用户简版只呈现最重要的一至三条，用“结论式短句＋决定性数据＋对定位的影响”，替代重复数据和泛泛优缺点；重要反证用一句限定保留。

## 3. 交付验收

- “需要成熟OS”“样本小”“跨试验不可比”本身只是常规核验，不能单独包装成洞见；需指向具体数据及其改变结论的原因。
- 对每个拟呈现洞见问：删去它是否会改变患者分层、产品定位或结论可信度？不会则移至底稿。
- 对最看好的方案主动写出最强反对证据，并核它是否足以改变偏好；不得只替既定结论寻找支持。
- 不用缺失当失败、低置信度当无效或显著性差异当组间差异；没有交互或机制证据时仅提出待验证解释。
- 如两轮定向补证后没有发现足够支持的重要额外信息，直接说明未发现可证实的新洞见，不为满足数量制造结论。
