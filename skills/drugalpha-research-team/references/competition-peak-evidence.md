# 竞争格局与销售峰值：联网补证与商业洞见

为研发位次、双轴竞争、患者及市场空间服务。先列会改变结论的缺口，再选来源；不默认遍历所有网站，也不要求所有任务都做患者峰值模型。当前流程允许公开联网补充；用户限定仅数据库时遵守限制，明确无法解决的缺口。

## 1. 补证触发与可执行路径

| 缺口 | 查找路径与实际动作 | 必须核什么 |
|---|---|---|
| 管线位次、入组或注册进度 | 用药名/别名＋登记号查[ClinicalTrials.gov](https://clinicaltrials.gov/)及中国药物临床试验登记平台；再查公司IR/原始会议与监管记录 | 研究目的、适应症/亚组、地区、真实阶段、首次/末例入组、完成或受理/获批的事实日期；登记预计日与实际日分开 |
| 获批标签与同适应症竞争 | NMPA/FDA/EMA批准/审评/标签＋对应正式指南；临床相对定位交临床成员 | 批准国家、标签人群/线数、突变范围及联合限制；加速/附条件与常规批准如实保留，不凭机制认定替代 |
| 国内销售、权益与历史商业资料 | [巨潮](https://www.cninfo.com.cn/)、交易所、[港交所披露检索](https://www.hkexnews.hk/homelcititlesearch.html)→对应年报/中报/公告/招股书→公司IR演示补充 | 产品/组合归属、财报期、币种单位、实际销售或合作收入、地区及会计说明；股东会交流与正式报表区别 |

| 价格、医保、可及性 | 国家/地方医保局当期目录与限定支付、采购平台挂网原条目、官方说明书、正式援助规则 | 地区、规格厂家、日期、生效期、支付范围；来源价性质和实际可及，不以目录纳入推所有医院已配备 |
| 权益和商业对标 | 许可/合作公告、公开协议附件、财报附注、对方IR交叉读 | 同分子/地区/适应症、独家与否、供货/版税/分成基数；全球产品销售和公司经济利益分开 |

## 2. 取证与停止规则

每条关键事实记录主体/分子/品牌、患者及地区、期间、单位、原值、原文页码URL、实际阅读范围、事实/预测/本研究假设、对结论的影响。区分“原文明确未披露”“当前工具未覆盖”“尚未取得原文”，不能混写没有患者/没有销售/没有竞争。

发现差异先核同分子、地区、财年、收入性质、品牌合列和版本。二手线索优先回原始披露，不能挑有利值。同一关键缺口连续两轮定向检索无有效新增后停止并收窄结论；其他仍可推进的问题继续，不为给排名或峰值无限搜索。

## 3. 从四条主线找重要信息

不只是列阶段、竞品数、人数与市场规模。优先核能改变资产位置的两三个问题：

| 常规表象 | 应追查的细节与可能影响 |
|---|---|
| “进度全球前三/国内首个” | 排名是否只在特定适应症/地区/技术路线成立，是否漏已上市或更早受理者，同阶段关键试验是否真正完成；若范围狭窄，收窄领先结论 |
| “同靶点很多/很少” | 有多少是真正同患者替代，有没有不同机制强标准治疗；拥挤与否不能只数试验行或公司数 |
| “后发也有更好疗效” | 临床是否在对应亚型/线数已可靠成立，能否覆盖足够患者，检测、价格或给药约束会不会抵消；差异化和可兑现分开 |
| “大癌种/大靶点” | 真正标签与细分亚型多少，目标线数到达率和检测可及如何；大疾病新发不能直接等于服务患者 |
| “全球同类销售几十亿美元” | 是否跨适应症/地区/联合、多品牌或多个分子；目标资产有多少可覆盖、商业权归谁；不以宽品牌规模验证窄亚型峰值 |
| “同类销售弱，说明市场小” | 上市年限、准入和供货、竞争、检测与公司商业能力，是否需求未释放；同时保留需求确实不足的反证 |
| “新增适应症再加一块市场” | 患者重叠、同药前后线使用、疾病自然史及本公司产品替代；不重复叠加患者或销售 |
| “医保后快速放量/降价后空间变小” | 实际限定支付是否扩患者，净价/销量是否有证据，药费与企业净收入是否混用；缺数据时给验证变量而不是先下收入结论 |
| “海外销售好就能兑现利润” | 自营、供货、版税或分成、地区权利和销售费用承担；将终端规模与公司可归属经济利益分开 |

每条洞见在底稿写：具体事实→商业解释→最强替代解释/反证→如何改变研发/竞争/市场判断→后续验证。公开只留关键判断及决定性数据，不把整套流程贴给用户。没有新洞见就如实说，不给任意分数或硬凑赢家。

## 4. 复核与案例验收

交稿前用下列情境自查，不需要为每个任务另跑全部工具：
- 若目标药是G12D专一、标杆覆盖全RAS：患者与可比销售不能用全胰腺癌/全RAS替代，临床优势回对应G12D。
- 若两款代号其实同分子、权益分中外：研发计数按同分子，销售及公司经济利益按地区/合同，不能合成两款全球独家产品。
- 若只有同靶点总资产数和某公司“领先”表述：没有核齐关键候选与事实日期，不给全球精确名次；同适应症不同机制标准治疗仍需覆盖。
- 若API年度数为百万美元、网页为亿美元，或某品牌包含多个药：先对齐单位和范围，不能造金额差异、拆分或重复加总。
- 若有大疾病人数和医保价、没有目标亚组/可及/净价：不给确定峰值或患者自付；保留变量和有来源的市场对标。
- 若已取证但尚未用真实公司验证整个工作流：只能说手册/参数校验完成，不能宣称商业化研究实测通过。

## 5. 把竞争与需求传导到商业判断

**进入市场时还能赢什么。** 当前研发位次之外，按催化剂已核窗口检查目标产品进入市场时的竞争：已上市标准会不会换代、关键竞品是否可能更早进入、前线使用是否减少后线可服务患者。未来仅做有来源的条件情景；不能从登记预计完成日推定竞品上市，也不能把今天领先当作上市后份额。

**患者为什么切换。** 对最重要患者段，用一行记录“当前实际治疗及未满足需求→本药最低必要价值/理想价值→临床已支持的部分→检测、支付、给药等采用阻碍”。最低必要价值是有依据的研究门槛，不是自行设定审批标准。差异化未获临床支持时，不能按最好疗效情景覆盖全部患者；保留有证据的耐受性/可及性切入口。不存在明确切换理由时，下调替代标准治疗的商业定位或保留份额未知，不只在风险栏写一句竞争激烈。

**销售预测先独立建立患者及份额假设。** 外部目标的隐含采用条件仅供另列比较，不能作为产品渗透率、份额或适应症分配的依据。 需要评估销售假设时，以患者与治疗暴露自下而上计算，并用同范围同类销售或已披露治疗量交叉检查。两种方法不共享同一组未经核实的假设作为“相互验证”，也不因落在任意倍数内就自动可信。若净月收入已知，可反算“年销售÷每治疗患者月净收入=隐含治疗患者月”；再用有依据的平均本年暴露换算治疗人数及占可服务人群比例。识别所需份额、检测覆盖或暴露是否超出证据；不能用PFS直接代替用药期，也不能用全年新患者假设人人完整治疗一年。缺参数则指出哪项假设决定空间，不凑峰值。

**已有销售的增量来自哪里。** 涉及放量判断时，区分新患者、持续在治、净价、适应症/地区拓展、汇率及渠道库存。只对已披露因素拆贡献；营收增长不能自动称处方量增长。对标产品尽量按上市年限和支付节点比较，缺净价/销量时不反推出虚假患者数。

上述工作按问题选用，仍围绕原四条主线；简版在已有竞争表注明进入市场时的主要威胁，在市场表保留决定空间的患者/采用/暴露假设。首段说明证据使商业定位上修、下修还是维持，尚未量化时说明方向及条件。综合决策模块发现只有大市场数字、无真实切换理由，或反算与结论矛盾却不修订时，退回相关市场/销售主张，并同步财务输入。

### 方法来源与采用边界

2026-10-28实际读取下列公开材料；这是适配后的研究流程，不表示外部技能已安装、已验证其表现或完成正式药物经济学评价。

- [wshobson：market-sizing-analysis](https://github.com/wshobson/agents/blob/main/plugins/startup-business-analyst/skills/market-sizing-analysis/SKILL.md)：借鉴总市场、可服务与可获取空间分层，以及多方法核对；不照搬示例份额/年限。
- [wshobson：competitive-landscape](https://github.com/wshobson/agents/blob/main/plugins/startup-business-analyst/skills/competitive-landscape/SKILL.md)：借鉴客户需求、真实替代方案及竞争优势持续性；不把软件特征打勾或任意定位坐标当临床优势。
- [xcrrr：market-researcher](https://github.com/xcrrr/claude-skills/blob/main/skills/business/market-researcher/SKILL.md)：借鉴细分和自上而下/自下而上差异解释；不采用其“两倍内即可信”的机械门槛，不自动发起访谈或调查。
- [WHO产品画像](https://www.who.int/our-work/science-division/research-for-health/optimizing-research-processes/product-profiles)：借鉴目标患者、最低与理想特征；不把研究画像当监管背书。
- [ISPOR预算影响良好实践](https://www.ispor.org/publications/journals/value-in-health/abstract/Volume-17--Issue-1/budget-impact-analysis-principles-of-good-practice-report-of-the-ispor-2012-budget-impact-analysis-good-practice-ii-task-force)：借鉴患者流入流出、当前/未来治疗组合与采用条件；支付方预算影响不等于药企收入或估值。
