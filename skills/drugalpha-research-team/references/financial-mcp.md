# 财务与估值：独立DCF数据调用

公司估值用 get_company_valuation 确定独立测算范围，并获取[估值报告](valuation-report-template.md)所需的平台参考资料。平台峰值、估值与参数只在参考估值处列示及核算，独立模型使用独立取证输入。板块估值及行业 PS 工具不用于独立模型。使用 Skill 内置的平台原生计算与导出流程，详见[DCF规范](valuation-dcf-workbook.md)。行情另取当前授权行情源。财报工具附带建议不扩大本任务授权。

## 财务数据来源边界

财务与估值模式及综合决策中的财务部分，不通过DrugAlpha取得财务报表、一致预期、现金、债务、股本、股价、市值或汇率；不调用get_company_research_inputs取得这些数据。优先使用客户已连接且有权限、适用于本市场及字段的iFinD／东方财富妙想（Choice）／其他金融MCP；缺项、失败或无适用连接时回公司IR、交易所/监管原始披露。具体执行见[金融MCP优先路由](financial-mcp.md)。DrugAlpha仍用于估值跟踪范围及临床、管线、竞争、流行病学、药价和催化剂；估值跟踪附带的财务/行情字段也不作为模型输入。范围选择的正峰值布尔规则不变。

## 客户金融MCP优先路由

财务与估值及综合决策中的财务部分，先发现客户当前已连接、可调用且有权限的金融MCP，包括iFinD、东方财富妙想（Choice）及其他金融数据源。按本次市场、报表字段和期间匹配能力，优先实际调用适用工具获取结构化财务与行情；不预设客户必须安装某个品牌，也不把终端整体覆盖视为MCP已开放能力。用户明确指定来源时遵从。

- 读取当前工具契约再调用，不编造接口名或权限。按公司及代码、市场、报告期、合并/母公司、累计/单季、币种单位提出查询；行情与财报分开，保留报价日期及财报期间。多个源可用时选覆盖适合者，不无差别重复调用。
- 无适用连接、无权限、失败或缺字段时，自动回公司IR、交易所/监管官方财报补齐；一部分成功只补缺项。已有连接的失败重试遵循其约束；连续两轮无新增停止扩展，注明缺口。不因没有金融MCP而要求客户必须安装或中止可完成的公开取证。
- 受限现金、存款可用性、债务到期、BD支付义务及期后融资仍回原始公告/附注核实。结构化结果与原文冲突，先核期间、单位、重述和口径，不能混拼；空值不能填0。
- 记录实际来源、所用字段、失败/缺项及回退原文。只发现工具或读取介绍不算已取数；网页数字不能冒充MCP返回。DrugAlpha继续承担范围选择及药物研究，不承担公司财务/行情取数。
- 客户自行连接并使用自己的授权。Skill不内置共享账号、密钥或固定付费依赖，不自动购买权限。

### iFinD接口选择与返回核验

以当前工具契约为准。已开放综合服务时，指定市场、财务科目或日期的查询使用get_security_indicators，港股传market="港股"、美股传market="美股"，query写清证券代码、报告期、合并口径、累计/单季及单位，单次少量指标。财报与日行情分开；本接口不支持高频实时行情。

get_stock_summary仅适用于A股概要，不支持具体日期/指标筛选，不能用于港美股或指定日收盘价。摘要接口无结果不能证明iFinD没有该市场覆盖，应先核综合指标工具是否可用。公告片段使用search_notice，日期表示公告发布日期而非财报期；片段不等于全文。

逐项核返回科目与所问科目、日期、单位是否一致；成功状态不等于成功取到指标。“定期存款”若重复返回“现金及现金等价物”，拒绝映射，单独明确科目重试一次，仍缺失回原始附注。实际报告期与解析参数如MRQ不一致时核原文，不自行认定已得到指定历史期；元字段中出现“亿”须按显示值正确换算。仅错误接口调用不计金融MCP取数通过。

### DCF 财务输入交接

- A/H 股 DCF 未指定提供方时按科目覆盖及当前可用性选择已连接的 Alpha 派、iFinD MCP 或其他已授权金融 MCP。超时后优先用可用连接补齐所需字段。查询后核证券代码、会计年度、合并范围、币种、单位和指标本身。费用及资本支出按扣减额正值归一，税项抵免和现金流保留方向。应付、定存、营运资本等均保留原财报口径。
- 交接 JSON 包含 `provider`、`securityCode`（如 `02595.HK`）、`currency: "CNY"`、`unit`（元／万元／亿元）、`scope: "consolidated_annual"` 和 `rows`。各行填写 `year`、`report_date`（ISO 年末日期）、`values` 与可选 `field_sources`。金额统一到该文件声明的单位。缺项填 null 或省略，实报为零时填 0。用 `field_sources` 对官网财报等补证字段标注实际来源。
- `values` 对应 `revenue`、`cost`、`gross_profit`、`sales_expense`、`rd_expense`、`admin_expense`、`sales_admin_expense`、`profit_before_tax`、`income_tax`、`depreciation_amortization`、`capex`、`operating_capital`、`operating_capital_change`、`operating_cash_flow` 等已验证科目。完整清单见 `scripts/dcf/packages/financial_data/mcp_history.py`。公司全股本和估值日净现金仍按各自口径另取。
- 用 `--mcp-financials` 传入 JSON。入口验证主体和报告期，换算为人民币亿元，交原生财务曲线处理。若最近完整年度收入缺失，先定向补证。其他缺项按 Excel 模型检查提示复核。

- 提供管理费用（或销售及管理费用合计）前，先以利润表及附注确认与研发费用是否重叠。各行用 `expense_scope` 对 `admin_expense` 和／或 `sales_admin_expense` 标明 `includes_rd` 或 `excludes_rd`。前者仅在原值确实完整包含同口径研发费用且该研发金额已取证时使用，运行器减一次并输出勾稽明细。部分重叠或口径不明时先回原文拆分，仍不能确认则缺项。若已有独立销售及管理费用，避免再提供两者的同口径合计。不得把资本化研发、财务费用或已进毛利的成本作为同一费用重复扣减。
- `equity_bridge` 提供 `as_of`（首个完整预测年前一年的 12 月 31 日）、`cash_equivalents`、`eligible_deposits`、`interest_bearing_debt`、可选 `other_debt_like`（仅计入未在现金流重复扣除的项目）、`shares_outstanding`（已发行流通在外的股数，含未上市股份，扣库存股）、按科目填写的 `sources` 和可选 `note`。金额沿用文件单位。确认定存可用性，避免与现金等价物重复加总。租赁或其他类债务按现金流处理方式统一口径；未纳入的项目在备注说明。
- 将桥接日、现金流起点和股本对齐。若改用期中估值日，先调整首年只计基准日后的现金流。净现金或股本缺少关键证据时，说明缺口，禁止把未经净现金调整的企业价值当作完整股权估值。

### 同类药费用必须实际取证

药费属于DrugAlpha药物数据，不能因公司财务改用外部金融源而跳过。对主要地区和用药场景先确定可比药及可比理由，实际调用get_drug_prices、get_drug_instructions、get_treatment_cost_framework（遵循当前契约及competition-peak-mcp.md）。自动选择可核规格，不例行要求用户确认；保留地区、规格、价格日期、剂量/频次、停药周及费用口径。年治疗费用按框架计算后÷12得到足年平均月费，不把实际短疗程总费用÷12。

Excel保留“规格单价→剂量/包装消耗→年费→月费→本品净价调整→患者月收入”的公式链及来源。支付标准/零售价不等于企业净收入，折扣、医保或渠道差异须给理由与敏感性；同类药销售数据不能替代价格取证。海外价格优先通过 DrugAlpha MCP 查当地本品或可比药；缺当地可用价格再联网取当地公开定价或可比原文。疗程优先实际暴露，无则以匹配队列mPFS作代理，并说明中位数与平均付费月差异。

无覆盖或调用受限时记录实际缺口，再用公开支付标准、说明书或公司原文补齐；缺证价格只能作条件敏感性，不当成有依据基准。仅写“净价是假设”不算药费取证通过。

## 估值跟踪范围读取

用get_company_valuation传query公司名及page.limit（最多50），或本次返回的合法公司ID；歧义先核主体。逐页沿用条件与本次nextCursor，读完才称完整范围。保留valuationSource及个人/平台版本日期；该公司个人模型优先，无个人模型由工具选平台，读取失败不擅自回退。

对每个药物的国内/海外条目分别核includedInValuation及对应峰值字段是否为正数（通常国内estimatedPeakSales、海外estimatedPeakSalesUsd，须以当前返回结构/契约为准）。不要用风险调整后峰值、估值总额或分成金额代替该判定；字段缺失/null不能当0或默认纳入，标待核。仅保留用于范围的身份、药名、地区、纳入标记、正值布尔、来源及版本。接口若连同其他数值返回，不代表允许采用它们；传给DCF计算的范围对象不包含具体峰值、估值、成功率、倍数、权益比例等参数。不要宣称服务端没有返回这些数值。

### 平台参考估值读取

只有来源确认为平台发布值时，才在第 03 节列为 DrugAlpha 平台估值。公司估值接口优先返回个人模型。收到个人模型时，使用已授权的官方平台发布页面或公司发布明细取得参考值。仍无法取得时保留第 03 节，说明平台发布值或逐药数据不可得。个人估值和独立测算均有各自来源标注。

平台部分保留同一发布版本的公司汇总、逐药行和倍数。确认分页已读完后，按国内归属峰值、商业化或传统业务的各自计价规则复核。海外先核真实计价基础，再复算风险权重、权益或分成、汇率和倍数。版本、公式或归属口径不明时标出缺项，保留可核实的原值。

地区/适应症条目缺失时用get_pipeline和公开披露核查，不编造接口字段。平台“海外”标签只定义候选边界，实际国家和权益另证。范围表逐条留纳入、排除和待核理由；无权限则报告范围缺口，不通过后台获取。

## 数据路由

药物销售输入按[第一数据源逐项路由](competition-peak-mcp.md#药物销售及-dcf-参数的第一数据源)取证。 Excel 的财务来源逐项写明实际数据库 MCP 名称（如 iFinD MCP、Choice MCP），或实际采用的公司年报、中报及报告期；同一科目用 MCP 核对、以财报入表时分别注明。

- 公司财务及行情：不用DrugAlpha。按下节及financial-evidence.md取公司IR/交易所原文，或用已授权金融源；Alpha派A/H结构化财务按用户AGENTS使用，美股回SEC。
- 管线、地区权益与催化：resolve_entities后get_pipeline/get_catalysts，实际合同原文核权益。
- 患者流：get_epidemiology目录及正文，按[商业化指引](competition-peak-mcp.md)补具体患者分母。
- 临床、当前标准与竞争：get_clinical_evidence/get_guidelines/get_competitive_landscape；空结果按峰值手册回退，核原队列，不以总体代替亚型。
- 价格与疗程：get_drug_prices、get_drug_instructions、get_treatment_cost_framework。按客户授权自动选可核规格；费用独立计算，支付标准不等于净收入。
- 可比实际销售：get_overseas_drug_sales，不能将平台预测或海外品牌合计当国内适应症销售。
- 客户知识库与联网：仅已授权原始资料；关键事实回公司IR、监管、试验及财报，记录来源限制。

DCF 的财务查询由宿主代理调用已授权 MCP，导出由 Skill 内置引擎完成。

## 临床及竞争取证的执行闭环

对主要收入驱动项，先按[商业数据指引](competition-peak-mcp.md)发现当前工具契约，以适应症/亚型/线数查询get_competitive_landscape，核必要分页、竞品阶段及当前标准治疗；不要将药名填入仅接受适应症的查询槽。用get_clinical_evidence和get_guidelines核临床优势、治疗路径、疗程依据；公开原文补最新进展。当前工具没有某能力时明确缺口，不编造参数或声称已调用。

临床无结果、只有混合/一线队列、缺目标药物或关键终点时，必须执行[峰值手册的临床补漏流程](peak-workflow.md)：

1. 核对象及已证别名、疾病解析、筛选和分页；用规范疾病名及疗线同义词改写一次。
2. 仍不足则扩大至疾病＋疗线，必要时疾病级，去掉检索标志物限制，在返回结果中筛药物及目标亚型。放宽召回不放宽研究问题；连续两轮无新增停止扩展。
3. 逐候选核组织学、突变亚型、既往治疗/线数、单联用、剂量、分析集和截止日；记录直接适用、邻近参考或待核。回PubMed/期刊、会议原文、试验注册及公司披露补临床关键数据及入组条件，记录来源日期。
4. 把适用性传回疗程、患者范围、份额与DCF情景；邻近队列不能冒充目标队列的mPFS。仍缺证据则保留条件区间和缺口，不让一次空返回变成“无临床数据”。

内部底稿记录实际查询、补漏结果、适用性与模型单元格；正文不堆日志，仅保留影响投资判断的证据与限制。

## 2. 外部财务及行情入口

先核公司和证券代码、截至日、报告期、合并/母公司、累计/单季、币种单位。港股查披露易和公司IR；A股查交易所、巨潮和公司IR；美股查SEC及公司IR。财报正文必须包含现金流及关键附注，搜索摘要不能替代原文。期后配售、回购、股数变化及债务到期分别取最新公告。

已连接Alpha派时按用户AGENTS调用query_financial_data，A/H财务和行情拆开查询；不假定支持美股公司结构化财务。其他金融数据源先核实际能力、授权和时间，腾讯财经/自选股等可作行情候选，不能由报价接口推断具备财报能力。未连接不声称已接入，改走公开原文。

保留报价时间和取数时间；延迟报价不得称实时。市值核币种、金额单位及股份范围，必要时用已核价格×同范围股数交叉验证。空值保持缺失，不能转0；代码、时间、格式不符时停止采用。关键现金、受限资金及承诺以财报原文复核。

## 5. 补证、失败与审计

Alpha派若开放，按AGENTS先定义证券代码、报告期、累计/单季、合并、币种单位，行情和财务拆开；列表到详情只用本次返回ID。其查询超时最多缩小重试一次，空值不填0；美股无结构化财务覆盖。不得用网页数字冒充该结构化返回。

DrugAlpha失败按返回动作处理，限流按提示等待；空结果核对象、期间、权限、分页后最多改写一至两次，连续两轮无新增停止。未开放财务字段如实说明，可在用户允许的公开资料内独立补证，不从后台读取个人模型。

内部保存实际请求、覆盖和分页、模型来源与时间、原始财报定位、独立参数证据、汇率和股数日期、公式和调整桥接。不向用户展示凭据、内部ID或数据库路径；用户正文展示证据链接和实际限制。只有真正取得或生成文件才称Excel/DCF已交付，不自动保存估值、通知、发布或部署。
