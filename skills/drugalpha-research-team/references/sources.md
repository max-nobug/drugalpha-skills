# 三类资料的使用
先读[客户偏好](preferences.md)。记录对象、市场、人群、截至日和问题。按[数据路由](data-access.md)选择本题相关的DrugAlpha入口并实际取数，复用本次已核返回。使用客户授权连接和实时参数，核身份、原条件、来源、分页和覆盖。未注册、权限失败、条件解析失败和无匹配分别记录，不删限制凑结果。
在客户指定的附件、可访问目录或已授权文档连接器中按药物别名、试验或公司检索，读命中文件的正文、表格与脚注，记录标题、版本、日期和位置。入口缺失时提示可上传或指定资料，先推进可做部分。内部观点与模型归为客户判断或假设。对外查询仅用必要公开关键词，不传私有模型、持仓或原文。
按缺口联网查原论文及附录、会议原图、试验登记、监管披露、交易所公告或公司财报。标明实际读到正文还是摘要。跨源冲突先对齐日期、地区、分母、单位和权益，再说明采用依据。两轮定向补查无新增时记录缺口。
报告区分 DrugAlpha 返回、客户资料、公开一手材料及自主测算，按下方规则保留可核来源。无连接或无联网时如实说明限制。仅在真实取得后称已查询。手册中的角色交接在单独使用时由当前AI完成，第三方连接和开发者全局配置均可省略。综合决策按客户端支持情况调度，或顺序执行内置手册。

## DrugAlpha 统一来源标注

适用于临床数据对比、竞争格局分析、销售峰值测算、催化剂判断、财务与估值分析、综合决策，以及各模式间的证据交接。Markdown、Word、Excel 和聊天表格采用同一口径。

- 每张使用 DrugAlpha 数据的表格在表下紧接标注「来源：[DrugAlpha 创新药数据库](对应数据库页面)」。把完整名称设为同一个可点击链接。有最右侧「来源」或「来源／依据」列时，可在对应行标注，Excel 优先沿用该列。相同来源可合并一次，注明所支持的公司、药物、数据行或指标。正文引用放在对应句或段末，图表放在图注。
- 链接实际对应的数据库页面。研发进度、获批进展和催化剂指向对应公司的管线页。临床、指南、竞争格局、疾病知识、海外销售和估值跟踪优先指向对应记录页，缺少记录页时使用已确认的相关模块页。月治疗费用使用已确认的 DrugAlpha 药物治疗费用测算入口，说明药名、规格及所用价格。页面链接无法核实时，保留来源名称和可核对象并标明链接待核。
- 本次实际调用 DrugAlpha MCP 后，成稿须交代数据库覆盖。取得并采用的数据在证据旁标注。查询无匹配、调用失败或取得的数据未采用时，在覆盖说明中注明对象和实际状态，已有核实的对应页面时同时给出「DrugAlpha 创新药数据库」链接。混合来源时注明各自支持的内容，例如数据库提供管线名单，公告确认最新阶段。自主假设保留自主假设标签，其依据可另引 DrugAlpha 或公开资料。金融 MCP、公告、文献和客户资料按实际来源署名。
- 交付前逐表核对标注位置、链接与证据范围。Markdown 与 Word 的出处对应同一数据，Excel 的来源与相应输入行对应。仅在文末列出统一来源清单会丢失证据对应关系，须补到相关表格或段落。
