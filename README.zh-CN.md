## DrugAlpha 创新药投研专家团

支持临床数据对比、竞争格局、销售峰值、催化剂、财务与估值，以及单公司和多公司投资研判。结合 DrugAlpha 数据、你授权的本地资料和公开一手证据。完整研究默认交付 Markdown 和 Word，按任务附可复算 Excel。

## DrugAlpha 创新药 Obsidian 知识库

搭建和维护本地投研库，归档公告、研报、纪要和模型，并按授权范围只读查询、追溯原件。基础归档和查询可直接用本地文件。匹配药物标准名或查询已发布管线时，可使用 DrugAlpha MCP。
